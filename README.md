# 📊 numpy_matplotlib_comprehensive_demo

A comprehensive collection of **notes and code examples** on **NumPy** and **Matplotlib** for data analysis, statistical operations, and data visualization using **Python**.

---

## 📘 Covered Topics

### 🧮 NumPy

- 🔹 Array operations and dimensionality (0D to 5D)
- 🔹 Reshaping arrays: 1D → 2D / 3D / 4D / 5D
- 🔹 Solving equations using `np.linalg.solve()`
- 🔹 Image handling using `matplotlib.image.imread()`
- 🔹 Matrix operations:
  - Rank
  - Trace
  - Determinant
  - Inverse
  - Power
  - Eigenvalues & Eigenvectors
  - Transpose
- 📊 **Statistics**:
  - Mean, Median, Mode (with `scipy.stats`)
- 📉 **Variability**:
  - Standard Deviation, Variance, Percentile

---

### 🎨 Matplotlib

- 📈 **Line Plots** with different markers, colors, and styles
- 📍 **Scatter Plots** with custom colors and edge styling
- 🥧 **Pie Charts** with explode, labels, percentage, shadow
- 📊 **Bar Charts** with custom colors and legends
- 📉 **Histograms** for:
  - Normal Distribution
  - Uniform Distribution
  - Poisson Distribution
- 🧱 **Subplots Layout** for combining multiple charts
