A comprehensive collection of notes and code examples on NumPy and Matplotlib for data analysis, statistical operations, and visualization using Python.

---

## 🧮 NumPy Topics Covered
- Arrays: creation, shapes, dtypes, indexing, slicing, broadcasting
- Reshaping: 1D → 2D/3D/4D/5D, flattening, ravel vs copy
- Linear Algebra: rank, trace, determinant, inverse, power, eigenvalues/vectors, transpose
- Equation solving: `np.linalg.solve()`
- Statistics: mean, median, mode (`scipy.stats`), std, variance, percentile
- Random: distributions, seeding, reproducibility
- Performance: vectorization vs loops, `np.where`, boolean masks
- Image handling: `matplotlib.image.imread()` basics

---

## 📈 Matplotlib Topics Covered
- Plot types: line, scatter, bar, histogram, boxplot, pie
- Styling: colors, markers, linestyles, grids, spines
- Subplots: `plt.subplots`, shared axes, layouts
- Labels: titles, axis labels, legends, annotations
- Colormaps and colorbars
- Saving figures: dpi, bbox_inches, formats (PNG/SVG/PDF)

## 🚀 Quick Start
```bash
# Clone the repository
git clone https://github.com/SakshiTamshetti/numpy_matplotlib_comprehensive_demo.git
cd numpy_matplotlib_comprehensive_demo
```

### Prerequisites
```bash
pip install -r requirements.txt
```

If you don't have a requirements file, install common libs:
```bash
pip install numpy matplotlib scipy jupyter
```

## ✅ Best Practices
- Use vectorized operations for speed
- Set random seeds for reproducibility
- Label axes and include units where relevant
- Use tight layouts (`plt.tight_layout()`) to avoid overlap
